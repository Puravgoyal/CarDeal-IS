# CarDeal IS

A planned full-stack Car Dealership Inventory System for Incubyte Round 1.

**Status: Stage Zero specification only.** Application code, runnable setup, tests and screenshots are not yet available.

## Planned functionality

Registration/login, protected inventory browsing/filtering, purchasing with stock control, and administrator inventory management with a persistent database.

## Proposed stack

TypeScript/Express, file-backed SQLite and React/TypeScript/Tailwind with Vite. Exact runtime, driver and testing versions will be recorded after setup verification.
